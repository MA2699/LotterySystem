Lottery Purchase and Draw System

## 功能特性
### 1. 用户管理模块
- 注册：用户名唯一性校验，密码长度≥6位，新用户默认赠送100元体验金
- 登录：账号密码验证，登录后自动加载个人余额与未开奖彩票
- 账户操作：余额实时展示、自定义金额充值（支持正数校验）、安全退出

### 2. 彩票购买模块
- 选号方式：手动选号（1-36区间，7个不重复号码）、随机选号（自动去重排序）
- 投注控制：投注倍数1-10倍可调，实时计算投注金额（每注2元）
- 记录查询：按购买时间倒序展示彩票列表，标注期号、号码、倍数及开奖状态

### 3. 抽奖管理模块（管理员专属）
- 动态开奖：号码滚动动画（150ms/帧），停止后锁定7个中奖号码
- 奖项判定：自动匹配所有彩票，按号码匹配数分级（7中=特等奖，6中=一等奖等）
- 测试模式：支持预设中奖号码，跳过动画快速开奖（用于调试）

### 4. 中奖与通知模块
- 奖金计算：按奖项等级×投注倍数自动核算奖金（特等奖500万、一等奖50万等）
- 自动发放：中奖奖金实时打入用户余额，无需手动领取
- 登录提醒：未读中奖记录在用户下次登录时弹窗提示

## 数据库脚本说明
在`doc/database`目录下提供两个核心脚本，支持数据库环境快速搭建与重置：
1. `init_database.sql`：数据库初始化脚本  
   - 功能：创建`lottery_db`数据库及所有核心表（user/lottery_ticket/draw_record/winning_record），初始化管理员账号（admin/admin123）；  
   - 使用场景：首次部署项目时执行，生成完整数据库环境。

2. `reset_lottery_complete.sql`：数据库清理重置脚本  
   - 功能：清空所有业务数据（保留admin用户）、重置表自增ID、恢复admin余额为1000元、创建新一期未开奖记录；  
   - 使用场景：测试环境数据混乱时执行，快速恢复初始测试状态。
